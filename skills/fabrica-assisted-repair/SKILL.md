# Fabrica 辅助装配修复

## 进入正确任务

先读项目 `FABRICA_ASSISTED_REPAIR_HANDOFF.md`，再读用户指定任务的短交接、实际配置和唯一执行账本。已有任务沿用原入口；新任务使用 [task-handoff-template.md](references/task-handoff-template.md) 建立最小交接。任务未指定时先只读列出可选任务/配置，不能擅选或继承 Beam 的运行次数、暂停状态或授权。用户已给出的任务、辅助方式和运行额度不重复询问。

修复迭代共用项目 `skills/simulation-repair-loop/SKILL.md`：多项已定位、互不冲突且能分别核验的问题组成一个修复包，一次正式验收；强耦合未知物理原因才拆对照。优先真实配置经过 worker 构建、框架名称转换和生产预检的无物理冒烟；按精确差异重验，复用未变域。先读瓶颈相关代码/原件，不默认加载 Beam 全历史或另一条路线。

## 先做任务适配，再复用机制

只在选择实现、定位缺陷或迁移时读 [implementation-map.md](references/implementation-map.md)。其中是已存在代码与适用边界，不是已经完成的通用库。先核当前权威源码身份和资产，再确认新任务：

- 零件/机器人逻辑名与运行时名、完整 frame 映射、坐标/单位、实际初始配置和安装顺序；物理 hand 连接锚点与控制 TCP 的相对变换分别记录，不能混用一个“腕—件变换”。
- 每件抓取面与目标接触对、工具坐标、实测腕—件关系；另一臂职责、已装件和环境几何。
- 原完成条件、允许的辅助类型、接触与稳定窗口、最终释放/回位要求，以及当前证据采样合同。

若已有共用控制模块，修复原入口并扫同族调用点；若 Beam 分支硬编码任务名/零件数/路径，先明确最小适配接口，不能复制一份巨型 Beam 控制器后逐件调常数。新模块抽取需分别核原任务兼容域和新任务，文档经验不算代码已复用。

## 辅助方法的关键不变量

- **抓住后保持关系**：双指接触几何/稳定资格达到该任务合同后，以同物理时刻实测位姿创建固定连接，冻结完整腕—件六维关系。固定连接也有求解误差；分别观测模型预测与 native 实测残差。不得用写位姿、清速度或关闭碰撞掩盖关系漂移；固定连接不能证明摩擦抓稳。
- **完整目标贯穿换段**：接受过的完整位姿与最终目标跨阶段连续；暂时超前量、入口负载偏移和阶段终点分开。停稳用有明确时钟的实际位姿运动核对原求解器读数，保留原稳定/限位门。只看到角速度大或误差超限，不直接调迭代数或速度。
- **双方和持件一起搬运**：检查最终限幅、SDK接受后的实际指令，包含双方机械臂、完整夹爪、随动持件、已装件及相关环境；按实际抓取关系和另一臂状态生成路径。明确接触对象对/阶段才可豁免。有限可见网格检查不冒充连续碰撞或接触形状证明。
- **在实测位置接住再释放**：先按任务装配父 frame 选择支撑；只有静止世界目标适合沿用世界约束，活动父件须用任务专属支撑。约束接住当前实测位置，确认夹爪实际张开后，再缓慢移动安装锚点到目标。保留碰撞与残差检查，说明最终支撑是否保留，不能称拆除支撑后自然稳定。
- **完成同时留下证据**：主成功、运动完成、严格独立后审分别记录。证书、独立 raw 状态和三视图按同 native 时钟核验，终止前刷新/采样顺序必须覆盖终态及合同窗口；缺测保留，不回填通过。Beam A44 曾主成功但终态独立 raw 缺帧，该缺口尚未由新运行修复。

## 迁移验收与交接

先保留真实旧失败输入、危险负例和可推进正例；局部检查指离线构建/回放或受影响测试，是否包含短物理必须明确。没有等价恢复证明的中段搭场景只算短调试，不算从头完成。

授权内按任务合同验收，固定机器后审一次，保留原报告及缺测、完整原片和必要片段。新任务用自己的源/工具/资产/配置身份、回退、账本与结果；按项目显式文档清单一次同步。日常仅更新短交接和已有记录，通用决策改变才改技能。不要把本技能当作新仿真授权或装配已成功的证明。
