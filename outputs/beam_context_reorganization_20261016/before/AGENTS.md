# Beam 工作规则

- 开始本项目的新对话或相关工作前，先读仓库根目录 `BEAM_REPAIR_HANDOFF.md`，并核对其中的服务器路径、提交和最新实验是否仍有效。
- 服务器源码是权威；本机外层目录是同步副本。当前审查候选、回退基线和本机 Git 工作树的准确路径由交接文件指定，不从目录名或记忆推断。
- 每轮分析、修改、实验或回退完成后，立即更新这同一份交接文件，并同步到服务器基线与候选根目录。记录事实、未决假设、保留/回退项、验证范围和下一步验收；替换过期结论，避免累积冗余历史。
- 同步后校验文件 SHA-256。若服务器不可达，明确标记同步待完成，不宣称两端一致。
- 保留原始日志和回退版本；不把接触、局部通过、离线测试或相同失败阶段当成完整装配成功。
- 当前授权、暂停和验证状态以用户最新指令及交接文件为准；不要把历史状态误当成永久限制。
