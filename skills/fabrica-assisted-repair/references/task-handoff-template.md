# 单任务短交接模板

新任务没有入口时使用；已有同义交接/账本则更新原件，不另建重复状态。建议在 `fabrica_tasks/<task_id>/HANDOFF.md` 放短入口，路径以实际项目结构为准。未知项写待核，不猜测或填入 Beam 数值。任务专用文档创建后纳入项目显式同步清单。

## 任务与权限

- 实际 task_id、生产配置入口、资产/布局、用户目标与本次授权范围：
- 唯一状态/执行账本路径；运行分类/计数规则、剩余额度、结束/失败/暂停条件：
- 最新用户指令及对应位置；没有启动授权时仅做已授权分析/修改：

## 权威身份与回退

- 权威服务器/源码、工具/资产/配置清单及 SHA、本机副本；是否有脏树：
- 当前候选及可用回退；源版本、文档版本、运行编号分别维护：
- 实际构建/预检/执行/后审入口（未找到即明列，不能拿 Beam launcher 直接跑新任务）：

## 当前任务合同

- 零件顺序、frame/单位、双臂职责、抓取资格/目标接触对、允许的辅助：
- 固定连接/世界支撑生命周期，哪些支撑最终保留，碰撞保持方式：
- 原目标/稳定/释放/回位/成功条件；原报告覆盖和证据采样合同：

## 当前修复包（只留未结项和本轮结论）

每项写：`现象和首失败原件 → 可证伪原因 → 修复及共用调用点 → 离线/短物理/完整验收方式 → 当前层级/缺口`。

分别验证的已定位无冲突问题可合并；仅需区分强耦合物理原因时拆对照。记录基线/候选精确差异、受影响输入域及可复用证据；不复制全仓测试清单或旧时间线。多项修复各有结论，整体回退保留。

## 最近一次结果与下一动作

- 原始运行/结论索引；主成功、运动成功、严格独立后审分开，未到门与缺测明列：
- 首失败窗口、同钟执行/接触/几何/三视图、完整原片/本机校验入口：
- 下一最小判别或验收；它是否已实现、已验证、已授权：
- 文档同步收据/显式清单入口，失败记 pending：

历史只链接原件，不在当前页重复维护计数与权限；账本是唯一当前状态。技能只记录方法，不能证明这个新任务已有完整成功或获得运行授权。
